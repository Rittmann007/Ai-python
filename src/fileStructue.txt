Your project is meant to be installable as a package, 
and package code is kept under src so the import path matches what gets installed. 
That reduces accidental imports from the working directory and 
makes local development behave more like a real install.
This style is common for projects that may grow beyond a one-file script.
It separates the packaging surface from your notebooks, experiments,
and other root-level files, and it avoids the import confusion 
that flat layouts often create.
